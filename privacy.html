Privacy policy

Tab Review Marker helps users assign review statuses and notes to web pages open in Chrome.

Data handled

The extension stores the page URL, page title, user-selected review status, optional user-written note, optional AI-access hint, and update time. This information is stored locally on the user's device using Chrome's extension storage.

The extension does not read page body content, collect analytics, use cookies for tracking, create user accounts, or transmit review data to the developer or any third party.

How data is used

Locally stored information is used only to display review state, apply favicon status markers, build the current-window review queue, and create an export when the user explicitly requests one.

Exports may be copied to the clipboard or downloaded as a file. The user controls whether and where exported information is subsequently shared.

Permissions

Storage
Stores review records locally.
Tabs
Identifies open sources and synchronizes status across duplicate tabs.
Scripting
Applies or removes favicon markers after the user selects a status.
Favicon
Obtains the page's existing icon so it can be preserved beneath the marker.
Offscreen
Provides the browser canvas used to compose favicon badges.
Optional site access
Requested one site at a time when the user asks to apply a marker. The injected script changes favicon elements only.

Data retention and deletion

Records expire after 30 days. Users can clear an individual mark from the popup or delete all locally stored review data from the extension's settings page. Uninstalling the extension also removes its local extension storage through Chrome.

Limited use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes

Material changes to this policy will appear on this page and in the Chrome Web Store disclosures before an updated version is published.

Contact

Questions can be submitted through the Tab Review Marker support page.
